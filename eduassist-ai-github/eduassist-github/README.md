# EduAssist AI

**ALLIN Company, From Bihar** — AI-powered study material generator for Indian students (School, Diploma, B.Tech).

## Features
- Upload syllabus image → get Notes, Q&A, Question Bank, VVI Questions instantly
- Solve previous year question papers (image or PDF)
- AI Voice Tutor — speak or type questions, get spoken answers
- Download study materials as PDF
- Supports School (Class 1–12), Diploma, B.Tech

## Setup & Run

### 1. Get OpenAI API Key
Sign up at https://platform.openai.com and create an API key.

### 2. Backend Setup
```bash
cd backend
npm install
cp .env.example .env
# Edit .env and add your OPENAI_API_KEY
npm run dev
```
Backend runs on http://localhost:3000

### 3. Frontend Setup (in a new terminal)
```bash
cd frontend
npm install
npm run dev
```
Frontend runs on http://localhost:5173

### 4. Open the app
Visit http://localhost:5173 in your browser.

## Deploy to Railway (Recommended)

### Deploy Backend:
1. Go to https://railway.app → New Project → Deploy from GitHub repo
2. Select your repo → choose `backend` as root directory
3. Add environment variable: `OPENAI_API_KEY=sk-your-key`
4. Railway will auto-detect Node.js and deploy

### Deploy Frontend to Vercel:
1. Go to https://vercel.com → New Project → Import your GitHub repo
2. Set root directory to `frontend`
3. Add env variable: `VITE_API_URL=https://your-railway-backend-url.railway.app`
4. Update `vite.config.ts` proxy target OR use `VITE_API_URL` in fetch calls

### Full-stack on Railway (Easiest):
Build frontend first, then serve it from backend:
```bash
cd frontend && npm run build
# Copy dist/ to backend serves it as static files
```
Then deploy only backend — it serves both API and frontend.
